# 🌐 Portfolio Website

Kişisel portföy sitem. HTML, CSS ve JavaScript ile sıfırdan, responsive olarak geliştirildi.

## ✨ Özellikler

- 📱 Mobil uyumlu (responsive) tasarım
- 🎨 Yeşil temalı, modern arayüz
- 🔗 Yumuşak kaydırmalı menü navigasyonu
- 💼 Projelerin listelendiği kart yapısı
- ⚡ Harici kütüphane yok — saf HTML/CSS/JS

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3 (Flexbox, Grid, değişkenler)
- Vanilla JavaScript

## 🚀 Çalıştırma

`index.html` dosyasını tarayıcıda açmanız yeterli. Kurulum gerektirmez.

## 📂 Dosya Yapısı

```
portfolio-website/
├── index.html    # Sayfa içeriği
├── style.css     # Stiller
├── script.js     # Etkileşimler
└── README.md
```
